# jasmine_oyster

Personal portfolio and blog of Jasmine Fortez, built with Next.js and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Structure

- `app/page.tsx`: landing page
- `app/layout.tsx`: root layout and site metadata
- `app/globals.css`: theme colors and Tailwind setup
